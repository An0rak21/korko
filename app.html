Ma session

L'ordre compte : connecte-toi, arme une session, puis fais partir la planche depuis le panneau Parc. Une planche qui part sans session armée ne produit pas de session — juste une alerte « sortie sans client » ci-dessous.
Compte ~70 s avant de voir le départ : le détecteur attend 45 s de silence, et la planche met ~23 s à sortir de portée. C'est ce délai qui évite les faux départs.

API disponible pour l'UI

GET  /parc                        état brut : horloge, stations, planches, sessions, alertes
GET  /api/stations                { stations:[{nom,branchee,t,libre}], planches, prix_minute, prix_max, t }
GET  /api/moi?jeton=…             { cle, nom, type, wallet, tubes, session, historique, messages }
POST /api/login/tel   {tel}                 -> { code_demo }   (pas de vrai SMS en démo)
POST /api/login/code  {tel, code}           -> { jeton }
POST /api/login/privy {user_id, wallet, …}  -> { jeton }
POST /api/armer       {jeton, station}      -> { session }
POST /api/deconnexion {jeton}
POST /api/sim         {action, balise}      relais vers le simulateur du kit
GET  /arme?client=+336…&station=A           forme texte, compatible kit
POST /evenements                            les stations poussent ici (contrat du kit)
